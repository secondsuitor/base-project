# Decision Log

A running record of choices made on this project and the reasoning behind them.
Newest entries go at the top. Short is fine: a few lines per decision.

## Template

```
### YYYY-MM-DD: Short title
**Decision:** What was chosen.
**Alternatives considered:** What else was on the table.
**Why:** The deciding factors.
**Trade-offs / revisit if:** What this costs, and what would change the answer.
```
